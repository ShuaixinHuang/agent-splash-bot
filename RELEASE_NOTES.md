AgentSplash Bot 0.2.0 — procedural desktop animations.

- Three real-time themes: Aurora, Ember, and Orbit.
- Window tracking on Windows, macOS, and Linux X11; standalone previews on Wayland.
- Adjustable duration, frame rate, and background opacity, with tray controls and click-through overlays.
- PNG export, validated configuration, atomic saves, and backups of invalid settings.

Requires Python 3.10+. Install the wheel in a virtual environment, then run `aurora-boot --demo` for a preview or `aurora-boot` for window tracking. This release provides a Python wheel and source archive, not standalone EXE or APP bundles. Application code: Unlicense; dependencies retain their own licenses.

Release packages and SHA256SUMS are preserved byte-for-byte from the original v0.2.0 release.
