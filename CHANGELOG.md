# Changelog

## 0.2.0

- Replace the previous implementation with a newly written Python / Qt application.
- Generate all animation frames procedurally; remove bundled video, image, font and audio assets.
- Add Windows, macOS and Linux X11 active-window adapters.
- Add three themes, standalone preview and offline PNG export.
- Add click-through overlays, bounded per-window intro tracking, tray controls and a settings dialog.
- Add recoverable JSON settings, finite numeric limits and atomic persistence.
- Publish a cross-platform Python wheel and source archive, with SHA-256 checksums.

This release contains the independently implemented application and its procedural graphics.
